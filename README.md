# Accounting System - Windows Desktop App

تطبيق سطح المكتب الرسمي لنظام إدارة المحلات والمحاسبة والمخزون للعمل على نظام **Windows**، مبني باستخدام **C# / .NET** ونمط التصميم **MVVM**، ومصمم للعمل بكفاءة عالية في المعارض والمحلات الكبرى مع دعم المزامنة والعمل بلا إنترنت.

## مميزات التطبيق والواجهات
- **Advanced POS View:** نموذج عرض شاشة المبيعات (POSViewModel) لإدارة السلة، حساب المجاميع والضرائب.
- **Inventory Management:** نموذج عرض إدارة المخزون (InventoryViewModel) والبحث المتقدم بالباركود وSKU.
- **Reports & Dashboard:** نموذج عرض التقارير ولوحة التحكم (ReportsViewModel) لحساب المبيعات وصافي الأرباح اليومية.

## التقنيات المستخدمة
- **Platform:** C# / .NET 8
- **UI Framework:** WPF / WinUI 3 / MVVM
- **Architecture:** MVVM & Clean Architecture
- **Local Storage:** SQLite & Entity Framework Core
- **Networking:** HttpClient & REST API Sync Engine
